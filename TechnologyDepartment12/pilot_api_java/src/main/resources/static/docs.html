免费下注接口使用 MD5 签名，key 按字母序排列后拼接密钥取小写。

⚠️ 注意事项

金额单位：分（1元=100分）。订单号必须唯一（幂等）。首次登录自动创建用户。

⚠️ 常见错误码

105订单号重复 — 此订单已处理过，视为成功
202渠道余额不足 — 联系平台充值
304用户不存在 — 请先调用 /createUser 创建用户
305玩家正在游戏中 — 等待游戏结束后再操作
307用户余额不足 — 下分金额大于当前余额
401签名验证失败 — 免费下注接口验签未通过

🔐 免费下注签名算法

免费下注接口需要请求签名，算法：

  1. 将除 sign 外的所有参数按 key 字母序排列
  2. 拼接为 key=value&key=value 格式（过滤 null 值）
  3. 末尾追加 key=密钥（密钥从平台获取）
  4. 对整串做 MD5 小写

重要：所有参数 key 必须为小写驼峰，expireAt 格式 yyyy-MM-dd HH:mm:ss （username / channel / count / activityId / sourceOrderId / expireAt / timestamp）
